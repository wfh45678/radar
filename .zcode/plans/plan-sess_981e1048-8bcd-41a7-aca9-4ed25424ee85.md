# v5.2.1 版本计划：统计聚合内存优化（MEDIAN/VARIANCE/SD 不再全量拉内存）

## Context

AGGREGATE 统计聚合特征的三个聚合函数（`MedianAggregateFunction` / `VarianceAggregateFunction` / `SdAggregateFunction`，v4.1 从旧 `AggregateCommandImpl` 原样迁移）在数据量大时把**匹配时间窗+搜索键的全部事件文档拉回 JVM 内存**再计算——每次事件上传实时触发，风险随命中事件数线性增长。而 Mongo 原生完全支持服务端计算：

- **VARIANCE/SD**：`$group` + `$stdDevPop`（总体标准差，Mongo 3.2+ 即支持）——与当前 Java 实现**语义一致**（都是总体口径 ÷n），SD 直接取 `$stdDevPop`，VARIANCE = SD²（更精确：不再从两位舍入的方差推导）
- **MEDIAN（精确）**：先 `count` 行数 → `$sort` + `$skip(n/2)` + `$limit(1~2)` **只取中间 1~2 行**回内存算中位数——语义与现实现完全一致（奇取中、偶取两行均值），内存 O(1)，不依赖 Mongo 7.0 的近似 `$median`

版本：**v5.2.1**（patch——纯性能优化，语义保持；主 pom 5.2.0 → 5.2.1）

## 改动内容（仅 3 个函数类 + 基类小改 + 单测）

### 1. `VarianceAggregateFunction`（服务端聚合）

pipeline：`[$match(filter), $group({_id:null, stdDevPop:{$stdDevPop:"$functionField"}})]` → `first()`：
- doc 为 null 或 `stdDevPop` 为 null（空集/字段无数值）→ `0.00`（沿袭 v4.1 空集返回 0 语义）
- 否则 `sd²` 后 `setScale(2, HALF_UP)` 返回

### 2. `SdAggregateFunction`（改为直接取 $stdDevPop）

不再委托 Variance（避免从舍入后方差开方的精度损失）：同一 `$stdDevPop` pipeline → `setScale(2, HALF_UP)`；空集 → `0.00`
- 两个类共享 pipeline 构造：`AbstractMongoAggregateFunction` 基类加 protected 方法 `stdDevPopRow(AggregateQuery q)` 返回分组后的单行 Document

### 3. `MedianAggregateFunction`（count + skip/limit 取中位行）

pipeline：`[$match(filter), $sort({functionField:1}), $skip, $limit]`：
- `n = mongoService.count(collection(q), filter(q))`；n=0 → ZERO
- 奇数：`$skip(n/2) $limit(1)` → 取 1 行原值（**不加 scale**，沿袭现语义）
- 偶数：`$skip(n/2-1) $limit(2)` → 两行均值 `scale 2 HALF_UP`（沿袭现语义）
- **保留**服务端 `$sort` 与精确语义，仅把"全量拉回"改为"取中位 1~2 行"，网络/内存 O(1)

### 4. 行为差异说明（CHANGELOG 标注，均为改善）

- VARIANCE/SD：字段含非数值的事件行，从"整特征报错隔离"变为"被 Mongo 忽略、按数值行计算"（更健壮）
- SD：从"两位舍入方差再开方"变为"全精度标准差直接舍入"（精度略提升）
- 单特征不再有 O(匹配数) 的网络传输与 JVM 内存占用

### 5. 测试

扩展 `AggregateFunctionRegistryTest`（已有 mock MongoService 模式）或新增 `MedianVarianceSdPipelineTest`：
- VARIANCE/SD：ArgumentCaptor 捕获 pipeline，断言含 `$stdDevPop` 且无全量 `find`；空集返回 0.00
- MEDIAN：奇/偶两用例——断言 pipeline 含 `$skip/$limit`（且 `$limit` ≤ 2）、先 count 后取行、奇偶中位数结果正确、空集返回 0

### 6. 版本与文档

- 主 pom `5.2.0` → `5.2.1`
- CHANGELOG v5.2.1 条目（Changed：性能优化 + 两点行为改善说明）
- 三个函数类 javadoc 移除"全量拉内存/大数据量慎用"标注（`featureTypes.jsx` 无相关文案，前端不动）

## 不做

- MEDIAN 近似算法（t-digest / Mongo 7.0 `$median`）——精确 skip/limit 已满足，近似列后续大数据量场景再议
- DEVIATION 不动（已是服务端 avg + 本事件值）
- 其他 7 种聚合不动（本就服务端完成）
